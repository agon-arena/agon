    Installer l’icône Agôn

    Clique simplement sur le bouton :

    Le lien d’installation sera disponible directement depuis la page.

    1. Ouvre cette page dans Safari (pas Chrome ni autre).
    2. Appuie sur … en bas de Safari.
    3. Appuie sur Partager.
    4. Choisis Ajouter à l’écran d’accueil.

    Sur Chrome ou Edge

    Une icône d'installation apparaît automatiquement dans la barre d'adresse :

    Si le bouton n'apparaît pas, cherche l'icône ⊕ à droite de la barre d'adresse.

    Sur Safari (Mac)

    Depuis le menu :

    1. Clique sur le bouton Partager.
    2. ✨Choisis Ajouter au Dock.
